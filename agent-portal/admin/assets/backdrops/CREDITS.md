# Backdrop media credits

Some clips require attribution — keep this file if you ever remove or reduce one, so the credit line still exists somewhere.

- earth-1.mp4, earth.jpg: replaced 2026-09-23. "Rotating Blue Marble" — NASA Goddard Space Flight Center (Reto Stöckli / Robert Simmon), 2011-10-06. **Public domain (NASA).** https://commons.wikimedia.org/wiki/File:Rotating_Blue_Marble.webm . The previous clip was a low-resolution (640x360) supplied file that looked blurry once stretched to fill the screen; this replacement is native 1280x720.
- earth-2.mp4: replaced 2026-09-23. "Animation of Rotating Earth at Night" (city-lights composite over Blue Marble imagery, Suomi NPP satellite data) — NASA, 2013-04-18. **Public domain (NASA).** https://commons.wikimedia.org/wiki/File:Animation_of_Rotating_Earth_at_Night.webm . Trimmed to the first 10s of the original 1920x1080 clip.
- waterfall.mp4, waterfall.jpg: replaced 2026-09-23 — the previous Eidfjord clip was real footage but a grey rock canyon with little color contrast once dimmed behind the UI. Now Krimml Falls (Krimmler Wasserfälle), Hohe Tauern National Park, Austria — the tallest waterfall in Europe. Filmed 2015. **License: CC BY 3.0 — attribution required.** Author: Erwin Lindsen, via Wikimedia Commons. https://commons.wikimedia.org/wiki/File:Krimmler_Wasserfaelle_Waterfall_in_Austria_Biggest_from_Europe_380m_at_the_top.webm . Trimmed to the first 24s (a single, consistently-framed shot from the ~98s source) and converted from .webm to .mp4 (H.264) for browser compatibility.
- christmas.mp4, christmas.jpg: replaced 2026-09-23 — the "Christmas" wave now shows a snowy winter forest instead of a city holiday-lights display, so it reads as a year-round wintry scene rather than a literal Christmas display. Aerial drone footage over Gallagher's Canyon, British Columbia, Canada, filmed 2017-12-30. **License: CC0 (public domain) — no attribution required.** Author: Extemporalist, via Wikimedia Commons. https://commons.wikimedia.org/wiki/File:Fresh_Powder_coats_the_forests_of_Gallagher%27s_Canyon,_British_Columbia.webm . The scene already renders a procedural falling-snow overlay (mdv-scenes.js `snow:true`) on top of this video.
- Galaxy is rendered live on the GPU (mdv-scenes.js), no media file.
