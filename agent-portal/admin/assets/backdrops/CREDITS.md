# Backdrop media credits

Some clips require attribution — keep this file if you ever remove or reduce one, so the credit line still exists somewhere.

- earth-1.mp4, earth.jpg: replaced 2026-09-23. "Rotating Blue Marble" — NASA Goddard Space Flight Center (Reto Stöckli / Robert Simmon), 2011-10-06. **Public domain (NASA).** https://commons.wikimedia.org/wiki/File:Rotating_Blue_Marble.webm . - earth-2.mp4: replaced 2026-09-23. Trimmed to the first 10s of the original 1920x1080 clip.
- waterfall.mp4, waterfall.jpg: replaced 2026-09-23, twice in one day. Now Kuang Si Falls, Luang Prabang Province, Laos — tiered turquoise limestone pools in dense jungle. Filmed 2017-11-12. **License: CC BY-SA 4.0 — attribution required.** Author: Jakub Hałun, via Wikimedia Commons. https://commons.wikimedia.org/wiki/File:20171112_Kuang_Si_Falls_in_Laos.ogv . Full 24s clip (static tripod shot), converted from .ogv to .mp4 (H.264) for browser compatibility.
- christmas.mp4, christmas.jpg: replaced 2026-09-23 — the "Christmas" wave now shows a snowy winter forest instead of a city holiday-lights display, so it reads as a year-round wintry scene rather than a literal Christmas display.
