# CAVYRE 16.11.64 — Cinematic Environment Color Waves

This build upgrades Galaxy, Christmas, Earth, and Waterfall from palette-only themes into full procedural portal environments. No image background assets are used.

- Atmosphere layer moved above the document background and below the portal shell so it is actually visible.
- Portal/shell/page backgrounds become transparent for cinematic waves.
- Primary surfaces become dark glass to reveal the environment.
- Galaxy: animated nebula ribbon + star parallax.
- Christmas: forest/ruby/gold light fields + drifting snow/light particles.
- Earth: animated orbital horizon + aurora/city-light sparks.
- Waterfall: vertical light falls + rolling mist.
- Native Settings cards are larger cinematic previews with LIVE PREVIEW labels and palette swatches.
- Reduced-motion remains supported.
