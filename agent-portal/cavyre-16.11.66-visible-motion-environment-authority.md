# CAVYRE 16.11.66 — Visible Motion Environment Authority

Root cause fixed: the cinematic atmosphere was rendered at z-index -2, below the opaque html Color Wave canvas. The animation existed but could not be seen.

This build keeps the current 14-wave Settings selector unchanged and adds a visible full-portal environment layer only for Galaxy, Christmas, Earth and Waterfall.

- Galaxy: moving nebula + parallax star field.
- Christmas: deep forest/ruby/gold atmosphere + gentle snow/warm light motion.
- Earth: animated orbital planet horizon + aurora/star motion.
- Waterfall: moving vertical cascades + rolling mist.
- No raster or remote background images.
- Existing 10 standard waves remain unchanged.
